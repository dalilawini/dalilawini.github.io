02 / TOOLCHAIN

Each tool has a dedicated manufacturing role

The fabrication process separates PCB design from manufacturing preparation and machine execution. This creates a clear chain from the original PCB layout to the CNC toolpath.

01

Altium Designer

The PCB is designed in Altium Designer, where the electrical connections, component placement and board layout are defined before manufacturing data is generated.

PCB Board layout
DESIGN Electrical design
OUTPUT Gerber manufacturing files
02

Gerber generation

The PCB design is exported from Altium into Gerber manufacturing files. These files describe the board geometry required by the fabrication workflow.

PCB DESIGN → GERBER → MANUFACTURING DATA
03

FlatCAM

Gerber files are imported into FlatCAM to prepare the geometry for CNC manufacturing. The PCB geometry is converted into machining toolpaths suitable for generating G-code.

03 / MANUFACTURING DATA

From Gerber geometry to G-code

FlatCAM acts as the manufacturing-data preparation stage between the PCB design files and the CNC machine. The resulting toolpaths are exported as NC G-code files.

04 / CNC FABRICATION

PCB milling with CNC 3018 Pro

The generated NC file is loaded into Universal Gcode Sender and executed by the CNC 3018 Pro. The machine physically mills the PCB geometry on the FR-4 material.

⌁
Engineering focus

This workflow demonstrates the complete transition from electronic PCB design to physical hardware. Altium defines the board, Gerber files carry the manufacturing geometry, FlatCAM generates CNC toolpaths, Universal Gcode Sender handles machine execution, and the CNC 3018 Pro performs the physical PCB milling.
